# BeautyGraph Practicum Deliverables

This folder contains the final deliverables for the BeautyGraph IMT 599 Practicum project.

BeautyGraph is a scoped information management prototype for explainable skincare formula comparison within one product category: leave-on facial moisturizers.

## Deliverables

| # | Expected Deliverable | Final Artifact |
|---|---|---|
| 1 | Cleaned product-ingredient dataset | `01_cleaned_product_ingredient_dataset.csv` |
| 2 | Controlled ingredient dictionary | `02_controlled_ingredient_dictionary.csv` |
| 3 | Ingredient function taxonomy | `03_ingredient_function_taxonomy.md` |
| 4 | Data dictionary and product-ingredient-function graph schema | `04_data_model_and_dictionary.md` |
| 5 | Baseline formula similarity module | `05_similarity_module.md` |
| 6 | Lightweight prototype | `06_prototype.md` |
| 7 | Short evaluation summary | `07_evaluation_summary.md` |
| 8 | Final written report and presentation | `08_final_report.pdf` |

## Project Repository Structure

The files in this folder are the final practicum deliverables or indexes to their canonical implementations.

Source code, tests, database scripts, and working project documentation remain in their original repository locations and are not duplicated here.

# BeautyGraph

BeautyGraph is a practicum prototype for explainable skincare product comparison.

**[Live Demo](https://lyue417.github.io/beautygraph/)**

The project connects products, normalized ingredients, ingredient functions, and transparent formula-similarity signals to support explainable product comparison.
## Current Scope

- Product data ingestion
- Ingredient list parsing
- Ingredient normalization
- Ingredient-function mapping
- Explainable product similarity
- Lightweight comparison prototype

## Disclaimer

This project is an information organization and product comparison prototype. It does not provide medical diagnosis, treatment advice, or clinical efficacy claims.
